**判定**：
- `v35_17700` 是**唯一同时满足「前向 0.70 ≥ 95 硬门槛」和「后向 0.55 ≥ 85」**的模型；
  前向 0.70=98（与 v22best 并列最高）、0.75=82（v26 58、v22 52）。
- **卸力机制成立**（step_profile，mag 0.55）：后向被推时 v26_17100 抬脚 1.8 次、
  峰值倾角 15.3°、位移 0.053m；v35_17700 抬脚 **2.9 次**、峰值倾角 **10.6°**、
  位移 **0.042m** —— 步子更多、倾角更小、漂移更少，正是「让位换重心」而非死扛。
  前向 0.70 同样：抬脚 4.6 vs 3.4、位移 0.254 vs 0.285、峰值倾角 28.0 vs 29.5。
- **站姿基本不受影响**：静止倾角 4.51°（v26 3.42°）、腿 RMS 0.3251（v26 0.3208）、
  静止占比 93%。成本约 +1.1° 静止倾角。
- **唯一短板**：后向 0.60 只有 22（v26 是 45）。五轮实验证明这是物理前沿
  （见 §4），v35_17700 是后向 0.55 与 前向 0.70/0.75 的交汇点。

## 2. 训练配方沿革（v32→v36，全部从 v26_17100 或其产物续训）

| 版本 | 核心改动 | 结果 |
|---|---|---|
| v32 | yield_step 2→3.5、窗口 0.30→0.45s、yield_walk 1.5→2.5、tilt 帽 42°、idle_lift−2（v28 机制）、姿态门控（v27）、课程顶 0.60 | 双稳态摆动：让步↔硬顶交替；18299 = 前向 93/83（大优）但后向 5 |
| v33 | + **yield_walk 方向门控**（推背才让位）+ 后向样本 0.20、yield_step 4.0 | 摆动缓和，仍无两点全优点 |
| v34 | + **非对称推力**（前向 1.0→0.70、后向 0.85→0.60）、课程顶 0.70 | 17500 = 前向 98/73（史上最强前向）、17525 = 后向 78/50 + 站姿 2.26° |

push interval 1.2–2.5s（不学 v27 的 0.8–1.6s 密集推力，密集+高幅被证毁站姿）。

## 4. 结论与下一步

1. **前后向在高幅值下的互斥是真的**。v32/v33 反复出现的「让步↔硬顶」双稳态、
   v36 的后向加压失败，都指向：0.70/0.75 前向要求「制动式站住/迈步」，0.60 后向
   要求「让位卸力」，同一策略在 20ms 控制周期下只能各占一头。
2. 「方向门控让位」+「非对称方向推力」+「采样配比」是把这条边界往两侧推的关键：
   前向 98（过 95 门槛）、后向 0.55=88、八项均值 61.3，全部超过 v26/v28。
3. 后向 0.60/0.70 若要再突破，建议从**扰动建模**入手（冲量摊平/足底摩擦-旋转
   耦合，见 VERSION_RANKING §7.4），而不是继续加大后向训练幅度 —— v36 已证此路不通。
4. 交付必须走 20-seed 扫描 + 60-seed 定版（v35 好点全在中途：17550/17700/18175，
   model_final = 85/0/0 不可用）。
